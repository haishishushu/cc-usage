鼠鼠已确认在当前任务直接实施。未创建／切换分支，未暂存、提交或推送；保留既有用户修改。

## 实现决策

- 平台目录为 Rust / TypeScript 共用 JSON；静态能力和本机来源检测分开。
- 原生适配集中在 `native_parse.rs`、`native_sources.rs`、`source_store.rs`，不为每个平台增加重复框架。沿用 requests / usage_events，独立存储积分、上下文、输入口径和上游状态。
- 本机监控不复制登录凭证；只启停本应用采集。Claude / Codex 才有已实现的外部配置应用。
- Gemini / xAI 官方 Key 单独只读检测，不与本机监控或消费版 OAuth 混用；不调用生成接口。未提供管理凭证时不尝试 xAI Management 余额接口。
- 真实零保留为零；字段缺失及无法证实的占位零保持未知。积分不换算 Token，上下文不等于剩余额度。
