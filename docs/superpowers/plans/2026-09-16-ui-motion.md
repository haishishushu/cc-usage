# 界面动效实施清单

目标：落实 prd/pencil-new.pen 的 20/20D、21/21D 动效提案，适配当前实际业务界面。

约束：沿用配色、布局和交互语义；不新增依赖，不操作 Git，不覆盖已有业务修改。当前连接管理已改为读取本机配置，弹窗动效应用于实际存在的移除确认及关于窗口。

- [x] 基础控件：index.css 定义节奏、按钮、开关、菜单、减弱动态规则；primitives.tsx 实现不等宽分段底板移动。
- [x] 页面及弹层：motion.ts 提供可清理的内容淡入和退出保留；接入 MainPanelWindow、SettingsView、OverviewView、SelectField 和连接弹窗。
- [x] 灵动岛：独立 IslandMotion 容器测量内容高度，展开前预留原生窗口空间，收起完成后释放；支持中途反向、动态内容、拖动及减弱动态。
- [x] 验证：构建；浏览器检查选中底板、开关、弹窗退出与焦点、快速展开收起、双主题及 reduced-motion。原生窗口行为无法通过普通浏览器完全证明，报告验证边界。

已先验证缺失行为：Playwright 点击本周后没有滑动选中底板，断言失败。

## 验收结果

- `pnpm --dir frontend build`：通过；保留原有 Tauri window 模块同时静态/动态导入的分包提示。
- `scripts/acceptance/motion.cjs`：浏览器逐帧检查通过。筛选切换时无关区域闪烁 0、邻项位移 0；43 帧灵动岛反向测试顶边稳定、标题持续可读；开关、菜单退出、弹窗焦点、减少动态效果通过。
- 弹窗快速关闭及重开：切换前后的 opacity、位移数值完全连续，重开后不会被旧退出计时器卸载。
- `scripts/acceptance/motion-window.cjs`：模拟原生窗口高度延迟，从 150px 增大到 400px，确认空间不足时暂停、足够时播放、收起后才释放空间；后台内容增高不重播其他内容淡入。
- 独立只读审查发现的快速关闭跳亮问题已修正：弹窗、菜单改用可反向的 CSS transition，Radix 通过不可见的动画生命周期保留退出节点。
- 未启动新的真实 Tauri 实例；Windows 合成器、显示器缩放及实际拖动停靠需实机确认，不将浏览器模拟当作桌面端验收。

## 防闪烁约束

只在用户交互标识变化时触发内容过渡，后台查询 loading/ready 不作为重播条件；不通过 key 重挂载页面。页面祖先不添加 transform，避免 fixed 弹窗定位改变。灵动岛使用实际窗口尺寸确认而非固定延时；标题常显，数据刷新仅调整必要高度。
