# Release 说明模板

发布新版本时，把下面的文案填好实际版本号与日期，粘贴到 GitHub Release 的说明里
（`Releases → Draft a new release → Describe this release`）。中英文都放，Release 页也是搜索入口。

---

## v0.0.0（发布日期）

### 新功能 / Highlights

- 一句话最重要的新能力
- 一句话次重要新能力

### 改进 / Improvements

- 界面与体验改进
- 性能或稳定性改进

### 修复 / Fixes

- 修复的问题描述

### 下载 / Download

- Windows：`CC-Usage-v0.0.0-Windows-x86_64-Setup.exe`（中文安装向导，装完即用）
- 官网与文档：https://haishishushu.github.io/cc-usage-website/
