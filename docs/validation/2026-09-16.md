## 发现并修复

1. 余额型网关缺少额度窗口被误判为连接验证失败。验证改为接受真实余额/配额/订阅/限流数据，余额为 0 仍有效；空响应与明确无效凭证拒绝。无额度窗口返回“不支持”而非“查询失败”。
2. 本机 Claude Key 自动发现丢失网关地址。候选返回对应地址，表单带出，后端使用本机凭证时同步取本机地址，避免错误发送到官方端点。
3. 卸载器默认清理 `CC Usage` 注册项，而应用实际写入 `CCUsage`。新增 NSIS 卸载 hook；明确卸载时移除实际键，升级时保留。
