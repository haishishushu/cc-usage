# 统一设置界面交付与验收

范围：已确认的 Pencil 统一设置页，连接管理 / 灵动岛 / 常规 / 外观 / 数据。沿用彩色线性图标、名称旁 Auth/API 标签、表格居中、长名称省略与悬浮全名、每行两个连接预览。

## 功能覆盖

| 分区 | 实现 |
|---|---|
| 连接管理 | 添加与校验、读取本机凭证、CLI 授权引导、更换 Key、暂停/重连、移除；暂停保留凭证和配置，移除保留统计 |
| 灵动岛 | 指定唯一连接、平台联动、来源能力说明、动态预览、置顶、贴边、免打扰、透明度和大小 |
| 常规 | Windows 开机启动、条件显示静默启动、刷新间隔、余额提醒；固定托盘策略、简体中文和系统时区按既定范围只读 |
| 外观 | 浅色、深色、跟随系统；与灵动岛同步、重启记忆 |
| 数据 | 实际路径及占用、打开目录、JSON 导入去重/导出、保留期、清理预览和确认；备份不包含凭证 |

## 本轮补齐

- 后端采用持锁的临时文件写入、同步与替换；成功后发布快照，失败保留旧值。各设置命令返回保存错误，不再伪装成功。
- 前端先订阅变更再读取，避免旧初值覆盖新事件；统一保存状态、失败反馈和重新读取；读取失败且没有已保存快照时禁用编辑。
- 灵动岛配置复用统一设置状态与连接列表，不再为唯一来源自动写入，切换平台时清除旧来源说明。
- 导入完成刷新容量并使旧清理预览失效；确认清理使用预览对应的保留天数。
- 修复关闭主面板后重新打开卡死：`open_main_panel` 改为异步命令。已复现旧版同步 IPC 留在空白 WebView，修复后销毁/重建两次通过。依据 [Tauri WebviewWindowBuilder 文档](https://docs.rs/tauri/latest/tauri/webview/struct.WebviewWindowBuilder.html)。

- Rust：67 项通过、4 项外部环境测试按原设置忽略；新增并发保存测试单独运行通过，共 68 项通过。
- 前端：23 项逻辑测试通过；TypeScript/Vite 构建通过。
- `scripts/acceptance/desktop.cjs`：真实桌面 UI 添加失败/成功、更换、暂停阻止查询、保留凭证重连、导入去重、无凭证备份、清理预览/确认、移除保留历史通过。
- `scripts/acceptance/settings.cjs`：五个分区、窗口开关、透明度/大小/刷新、余额提醒、跨窗口主题、保留期、托盘同步、6 类非法输入拒绝、页面重载通过。

- `scripts/acceptance/settings-restart.cjs`：重启真实隔离进程，11 项设置全部恢复，主面板销毁重建两次通过。
- 截图：`output/acceptance/settings-complete-dark.png`、`settings-save-failure.png`、`data-flow.png`。
- 最终前端构建通过；保留既有 Tauri window 静态/动态导入分包提示，不影响构建。测试应用与合成网关已关闭，原有开发进程未关闭。

## 边界

测试仅使用隔离数据及本机合成网关。没有更改用户开机启动注册表，没有执行 Windows 重启，没有使用真实账号完成外部授权。静默启动开关本次验证持久化，既有启动策略测试仍通过；这些不能替代真实登录启动或各供应商账号联调。语言、统计时区、数据库迁移的既定只读范围未扩大。
